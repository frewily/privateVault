位置：**手机 OpenList 的内置网页 → 管理 → 存储 → 添加 → 选择 Crypt**。应在存储添加表里填写库密码，避免误填到 App 的“设置管理员密码”功能。界面文字若与表不符，先说明字段名称，保持原有设置。

| 目录名加密 / Directory name encryption | `true` |

如果表里显示相关通用选项，本轮启用签名及 Web 代理；WebDAV 策略使用代理。只设置这一条新测试存储，不修改全局网络/权限。

路径假设：普通入口挂载在 `/百度网盘`，按用户报告的入口名称及测试区位置拼接；手机保存前需核对该完整路径确实到达测试 `cipher/`。显示名称与实际挂载路径不一致时先停，不凭猜测扩展到其他目录。

v4.2.5 的默认名称加密为 `off`、目录名加密为 `false`、名称编码为 `base64`，与本轮 B1 profile 不同。因此这三项必须显式填写，不能只填密码/salt 后沿用默认值。
