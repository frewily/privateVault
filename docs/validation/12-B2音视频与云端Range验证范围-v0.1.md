## 2. 操作次数和顺序

1. 沿用唯一百度驱动及现有 Crypt 视图，检查测试根、已有图片和预期子目录，拒绝未知对象及同名冲突。
2. 普通/加密音频分别上传一次并完整读回；普通/加密视频分别上传一次并完整读回。每个对象最多一次应用级上传，不整文件自动重试；长度及 SHA-256 必须与原样本一致。
3. 停止并恢复测试核心，在新的空临时缓存目录下做视频 Range 验证；核心数据库与最新凭证状态保持同一份，不新增授权或第二个百度刷新者。
4. 在新开的本机测试浏览器页中验证普通/加密音频播放进度、视频解码和快进；不查看用户原来的百度授权页，不操作原 OpenList。
5. 只停止本次测试进程，保存脱敏证据与截图；云端对象、测试配置和恢复材料保留。

只有普通与加密四份完整读回通过后，才继续范围读取与页面播放。若遇权限、限额、网络、未知目标、对象冲突或完整性错误，停止后续云端操作；不另换 app 参数或重新授权。

## 3. 视频 Range 与冷启动定义

普通和加密视频分别检查 7 项：首部 64KiB、跨 64KiB 明文块边界、中段 64KiB、末尾 64KiB、最后 500 字节后缀范围、最后 500 字节开放结束范围、超出总长的非法范围。

正常范围应为 HTTP 206，`Content-Range`、明文总长、响应长度与原始区间字节一致；非法范围应为 HTTP 416，并返回正确总长。两条链路合计 14 项。

首、中、尾与跨块试次各使用新启动的核心与新的空 TempDir，且该进程先前未读取视频内容。后缀、开放结束与非法范围可以接续运行，但单独标明非独立冷启动，不混为冷试次。

“冷启动”只指本机核心/本轮缓存，不声称清空百度、CDN、操作系统全部缓存或模拟真实移动弱网。完整读回文件留在报告目录，不被挂为本地存储来服务范围请求。

## 4. 上游读取量观测

继续使用本机 TLS 字节转发器，保持现有允许主机、证书验证、直连拒绝和本机 DNS 规则，不解密 TLS、不读取请求内容或捕获其他应用流量。

每个范围试次在准备本地签名地址后，记录转发器累计入站字节的前后差值，并记录到响应头、首字节和完成的时间。差值包含必要的 TLS/元信息开销，是读取成本的保守观测，不冒充精确媒体载荷；不以本地 206 单独判定高效 seek。

64KiB 范围在本样本下，若上游增量不超过 1MiB，可作为本轮“未读取整段前缀”的支持证据；超过时记录放大倍数及是否接近文件前缀/全长，不笼统写成高效快进通过。极短跨块请求按加密块对齐解释，不把两字节响应机械要求为两字节云端传输。

范围试次入站增量安全上限为 8MiB；触及上限就中止该读取并记录，不为了拿到 206 继续消费大段前缀。出现此情况停止后续测试并保留部分结果。

## 5. 总资源与网络预算

- 本轮转发器 TLS 隧道累计预算 512MiB，包含上行、下行、握手/元信息、完整读回、Range 与页面播放，跨核心重启继续累计。它不包括 DNS、环回和 TCP/IP 头部，不能称系统全网硬配额。
- 预计四个对象的上传与完整读回约各 87.4MiB，页面播放和 Range 另计；触及累计预算就停止，不自动提升。
- 临时工作区操作预算 2GiB，系统保留至少 15GiB。记录采样点与观测最大值，不声称有内核磁盘配额或精确瞬时峰值。
- 单任务、上传线程 1；不做压力测试或并发吞吐基准。驱动内部仍可能重试，应用级次数与内部尝试区分。

## 6. 页面播放验收与边界

使用发行包的 OpenList 页面和内置播放器，通过仅本机监听的临时核心读取测试目录。生成的测试管理员凭证只在本机工具内部使用，不输出或导出；真实百度/库密钥不送入浏览器测试代码。

检查图片外的普通/加密音频计时推进，视频时长、解码尺寸、当前帧/进度变化、跳转到中段和尾段后的恢复。记录实际浏览器、媒体错误与本机读取路径；只截取不含秘密的自制样本画面。

样本静音，所以只能验收读取、解码和播放进度，不能证明扬声器输出、ASMR 音质、后台/锁屏、蓝牙或 Android 播放。外部播放器、转码、字幕、多音轨和其他编码不在本轮。
