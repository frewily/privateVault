## 2. 已保留的配置修改

- 构建脚本默认选择 Release，显式 `debug` 保留诊断入口；这是构建配置入口，**不是已验证的 Release 成品**。仍默认离线，缺依赖会失败，不降级为大 Debug 包交付。
- Release 使用 Dart AOT、R8 与资源裁剪，仅 arm64-v8a。原生库改为 APK 内压缩、由 Android 安装时提取；减少传输与安装后占用不是同一个指标。ELF 16KB 对齐仍须检查，压缩条目不套用直接映射所需的 ZIP 16KB 偏移要求。
- 保持 `dev.privatevault.w01` 和既有开发证书；候选版本为 `0.1.0-w01a.2` / code2。Release 缺少原签名文件时拒绝生成替代密钥；仍是本地开发签名方案，不是生产签名系统。
- 保留 gomobile 的 Java/JNI 名称，扩展 APK 检查器区分 Debug 与 Release、压缩策略、调试载荷、版本与既有证书；Release 将检查实际裁剪后 DEX 中的生成桥接类和关键 native 入口。
- 发现直接 Gradle 构建沿用了 Debug 的插件注册文件，而 Flutter 3.47.5 会在 Release 依赖中移除 `integration_test`。新增小入口调用**固定 Flutter 自身的生成器**，按所选模式生成 Android 注册文件；不手改模板、不把测试插件塞进 Release、不修改共享 SDK。该入口使用 Flutter 内部 API，随项目锁定版本维护，升级时须核对。

没有更换 Crypt 算法、裁剪更多核心功能、修改 Dart 业务或 Mac 宿主。严格核心驱动编译裁剪仍未完成。
