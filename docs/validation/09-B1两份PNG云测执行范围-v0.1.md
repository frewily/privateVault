执行时先验证本机限制、转发和 TLS 行为；现有系统代理保持不变，只设置新进程自身的代理环境。若无法按该范围可靠运行，不静默放开直连或改动全局网络，先记录具体障碍。

这里是执行提案，不是已经通过的隔离/代理能力。其连接字节统计也不代表已完成 B2 的云端高效 Range 验收。

## 4. 会发生的真实请求及数据使用

获准启用后，核心会内部读取本次新测试凭证进行百度请求；不在模型输出或命令行参数中展示值。初始化可能请求账户基本/会员信息；凭证错误时驱动可能通过已选 OpenList 服务刷新并保存新值。此后的唯一凭证更新者是本次百度驱动，不运行第二份复制链。

文件操作仅针对已选新根：确认空目录、创建子目录、上传普通 PNG、完整读回、创建 Crypt 子视图并上传、解密完整读回，以及对测试密文名称/必要格式头作有限检查。遇到目录非空或对象冲突即停，不覆盖已有对象。

若出现重新登录要求、非预期应用/权限或原挂载异常反馈，停止，不申请新应用、不循环重新授权、不修改原挂载。

## 5. 样本、次数与成功条件

| 项目 | 上限或条件 |
|---|---|
| 明文输入 | 一张内部生成的 PNG，9,763 字节，复用阶段 A 摘要 |
| 普通云端对象 | 1 个 |
| Crypt 云端对象 | 1 个，预计 9,811 字节，参数显式匹配标准名称/目录加密与 base32 编码 |
| 预计对象总量 | 19,574 字节，约 19.1KiB；不是总网络流量上限 |
| 应用级完整上传 | 每个对象最多 1 次；不另做整文件重试 |
| 完整读回 | 普通和解密视图各 1 次；长度与 SHA-256 必须匹配原 PNG |
| 密文观察 | 限该测试子树的名称和必要格式头，不全量扫描网盘 |
| 任务并行 | 串行，上传线程 1 |
| 空间预算 | 临时工作区 2GiB 操作预算，系统至少保留 15GiB；如实记录采样，不宣称已建立强制磁盘配额 |
| 未执行项 | 视频、音频、来源站、故障注入、令牌到期、三端及正式资料库 |

共享服务的实际应用审核/配额未取得。按这次明确的小范围顺序探测，遇到权限、限额、网络、完整性或未知目标错误即停止后续步骤，不通过修改接口、换第三方 app 参数或不断重试继续。

驱动内部请求/分片仍可能自动重试；一次上传涉及多个 API，不能承诺严格“两次请求”。如发生内置重试，报告会区分控制器动作与底层尝试，不把对象大小当作流量硬上限。

普通阶段失败，不继续加密阶段。HTTP 200、对象存在或进度完成都不替代长度和完整读回摘要检查。
