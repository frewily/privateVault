## 2. 用户操作

以下为已完成接收所用的操作步骤，保留供记录，不要求用户重复。新的推进范围见[两份 PNG 云测提案 09](09-B1两份PNG云测执行范围-v0.1.md)。

### 第一步：先打开接收工具

在你自己的终端粘贴并执行下面这一行。它只启动本次本机接收工具，不需要填写任何凭证参数：

```sh
/private/tmp/privatevault-b-authorization-20261027-a0_gvu7c/receive.command
```

看到“粘贴新的 Access Token”提示后，先让终端停在这里，再去网页进行授权。不要把凭证粘贴到普通命令提示符或聊天框。

### 第二步：完成一次网页授权

1. 在浏览器打开 [OpenList 官方授权工具](https://api.oplist.org/)。
2. 选择百度网盘的验证登录方式，启用“使用 OpenList 提供的参数”或“使用官方参数”一类选项。源码中的候选分支为 `baiduyun_go`＋服务预设参数；不选择 OOB/手动登录，也不填写自己的应用密钥。
3. 只进行一次“获取 Token”或对应登录操作，在百度页面由你本人登录、查看实际应用名称及请求权限并确认授权。如应用或权限不符合预期，停止。
4. 到达结果页后不要再点“刷新令牌”，也不要将结果填回原挂载。

以上名称来自官方文档和已核对源码，实际页面可能略有不同。若遇到不匹配、失败、验证码之外的异常操作要求或不明跳转，停止并只报告简短状态，不反复授权，不发送包含凭证的截图或原始错误。

从登录到回调完成，由用户私下操作。模型不读取该页 DOM、地址栏、剪贴板或截图。

### 第三步：私下保存两个结果值

1. 从结果页只复制新的 **Access Token / 访问令牌值**，切回仍在等待的接收终端，粘贴后按回车。
2. 终端出现 **Refresh Token / 刷新令牌** 提示后，只复制对应的新值，粘贴并按回车。
3. 粘贴时不会显示字符，这是隐藏输入的正常表现。看到“保存完成”才表示本机接收流程完成。

不要复制回调链接、完整 JSON 或旧挂载中的值。输入错误可按 Ctrl+C 取消；工具不会覆盖已有接收文件，也不会打印输入内容。

如果已经保存过，不要反复运行来覆盖。若工具报错，只报告“接收未完成”；不要将错误前后的私人页面或凭证文件发到聊天中。

### 第四步：只回报非秘密状态

回到聊天，报告：

- 是否“授权并保存完成”；
- 授权页面显示的应用名称及权限大意；
- 如果正常使用原 OpenList 时发现登录异常，说明状态即可。无需为了测试反复刷新或重新登录旧挂载。

模型后续只能查看本次辅助工具的无秘密接收状态与文件权限，不能把“已保存”当成百度账号请求成功、上传成功或新旧刷新链独立的证明。
