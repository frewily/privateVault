## 3. 两项必须保留的实现差异

**尚未做到严格编译裁剪。** 上游离线工具和搜索实现间接导入其他驱动。Android 目标依赖图仍包含 115、115_open、123、123_open、189pc、guangyapan、pikpak、thunder、thunder_browser、thunderx、openlist 等包。自有启动限制会从构造器及能力注册表中移除它们，但它们的代码仍编译在内。不能把这份 AAR 称为“仅编入三种驱动”；严格裁剪仍未完成，也不宣称支持这些额外提供者。

**实际 Go 模块组合有变化。** 固定的 gomobile 需要较高版本的部分 `golang.org/x` 模块，Go 的最小版本选择使组合发生以下变化：

|---|---|---|
| crypto | v0.56.0 | v0.58.0 |
| image | v0.45.0 | v0.47.0 |
| net | v0.58.0 | v0.61.0 |
| sync | v0.22.0 | v0.24.0 |
| sys | v0.47.0 | v0.49.0 |
| term | v0.45.0 | v0.47.0 |
| text | v0.41.0 | v0.43.0 |
| tools | v0.48.0 | v0.52.0 |

OpenList 源码提交和 Crypt 实现没有替换；但依赖图不是未经改动的官方发行组合，不能省略上述差异。公开锁定文件为 `toolchains/w01-android.go.mod`、`toolchains/w01-android.go.sum`；叠加脚本核对原始/锁定摘要并拒绝未知修改，AAR 构建使用只读模块模式。Crypt 业务及既有资料兼容性仍须在对应工作包验证，本轮 Local 样本通过不代替它。
