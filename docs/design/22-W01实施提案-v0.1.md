## 1. 完成这一步后的可见结果

打开一个独立的 PrivateVault 开发版窗口，能看懂本机服务正在启动、已经就绪、已经停止，或为什么启动失败；可以启动、停止、重试，并通过自己的本机核心列出和读取一张自制测试图片。

这一步证明“PrivateVault 自己能管理核心”，为后续上传和播放建立基础。窗口中暂不出现不可用的账号登录、网盘绑定、下载任务或媒体库功能入口。现有 OpenList 应用及其配置、百度网盘、个人媒体都不作为 W01 输入。

推荐先执行 **W01-M：Mac 宿主**，之后执行 **W01-A：Android 桥接**。这是同一 W01 的内部顺序；完成 Mac 后只能记 W01-M 通过，不能把整个 W01 或完整首版写成已完成。

## 4. W01-M 的职责与接口

### 4.1 结构

Flutter 界面只持有适合展示的状态。CoreHost 管理子进程与会话，OpenListAdapter 仅提供这一步需要的版本、认证和测试目录读取。Swift 平台桥接负责应用容器位置、受管理辅助程序位置及必要的进程身份核对。

| 契约 | 输入 | 输出/行为 |
|---|---|---|
| start | 固定核心清单、应用自有目录、测试模式选项 | 启动或等待同一启动操作；返回状态，不返回管理员口令给界面 |
| stop | 当前受管理实例 | 正常停止并确认退出；必要时只结束身份已证明的自有子进程 |
| snapshot / watch | 无秘密的查询/订阅 | 状态、核心版本、错误类别和可执行的下一步 |
| probe | 内部受控会话 | 进程存活、HTTP 可用、认证成功和测试存储可读分别核对 |
| readFixture | 固定测试标识 | 自制 PNG 的名称、长度、内容及摘要核对结果；不接受任意本机路径 |

本机地址、令牌和进程句柄由内部 ManagedCoreSession 持有，不作为 UI 状态、普通日志或跨端同步记录。W01 不开放用户输入原始核心 URL、管理员密码或任意存储路径的入口。

### 4.2 Android 的后续边界

W01-A 复用同一 Dart 契约，通过自有 MethodChannel 和非导出的 Kotlin 服务承载 Go/AAR。不能调用现有 OpenList Mobile 的私有桥接来冒充完成集成。

Go 核心具有进程级状态，现成 Init/Shutdown 函数不能证明可无限次重初始化。Android 优先评估将核心放在应用自己的专用服务进程，控制请求与状态通过受限 IPC 返回；停止、异常退出及再次启动需要实际核对。若要结束该专用进程，必须限制为本应用拥有的核心进程，不结束主界面或其他 App。

此阶段先验收应用前台使用，不承诺锁屏、无限后台或自动订阅。前后台切换时的停止/重建语义在 W01-A 冻结时列清，不直接照搬上游长期服务权限、唤醒锁或密码日志。安装到手机时使用独立应用 ID `dev.privatevault.w01`，不覆盖 OpenList；安装及 USB 调试操作属于 W01-A 的单独范围。

## 5. 生命周期与本机安全约束

### 5.1 何时才叫“就绪”

状态采用 STOPPED、STARTING、READY、STOPPING、FAILED。只有以下条件全部满足才能展示 READY：

1. 核心清单、平台/架构、原始归档摘要符合预期。
2. 本次启动确实拥有该进程与独立目录；不是连接到碰巧占用端口的别的服务。
3. 核心监听地址为 `127.0.0.1`，版本符合固定清单。
4. 本机认证成功，访客不能读取测试目录或执行管理操作。
5. 自有 Local 测试目录能列出并读回预期 PNG，名称、长度和摘要相符。

OpenList 固定版本默认配置地址为 `0.0.0.0`，所以必须在首次启动前写入自有配置并改为回环地址；不能先以默认地址启动后再改。关闭不用的额外监听服务。先完成认证与访客限制，再注册测试存储。

### 5.2 幂等、冲突与异常

- 连续点击启动，共享同一次启动结果，不产生第二个核心；连续停止也不会报错或误伤其他进程。
- 启动中收到停止，取消就绪探测并清理自有子进程；停止中再次启动，等待停止完成后再开始，不能同时复用数据库。
- 初始开发参数：启动就绪上限 30 秒，正常停止等待 5 秒，必要的自有进程结束再等待 3 秒；端口冲突最多更换 3 次。它们是 W01 开发参数，不直接成为产品所有任务的默认值。
- 端口先探测后绑定存在竞争窗口，必须处理核心实际绑定失败。未知占用者一律不接管、不关闭。
- 正常退出应用时停止核心，不将关闭窗口隐式解释为继续后台运行。核心意外退出时界面进入 FAILED，不停留在 READY。
- 界面被强制结束时，子进程可能短暂残留；重新打开需先对账。身份核对须结合受保护的实例标识、可执行文件位置、进程开始信息、数据目录及认证结果。不能仅凭 PID 或端口判定所有权；无法证明时拒绝自动结束，并给出可处理说明。
- W01 不承诺任意崩溃下瞬时清除所有进程；必须实际记录强退后的结果及恢复动作，不能用正常退出代替该用例。

### 5.3 目录、签名和秘密

- App Sandbox 保持启用。测试数据与核心配置位于本应用容器中，由平台接口取得实际路径；私有目录权限目标为 0700、秘密文件为 0600。不扫描用户其他目录，不要求全盘访问权限。
- 原始公开核心归档保留固定摘要；构建时将独立副本放进新开发版应用的 `Contents/Helpers/`，为自有辅助程序配置沙盒继承和本地开发签名。原始归档及已有 OpenList 应用不被重新签名或改动。
- 主应用保留 Flutter 调试需要的原有 JIT/网络例外，显式添加本机 HTTP 客户端能力；服务只监听回环。辅助程序的签名/沙盒继承仍是必须通过的集成验收，不是已经成功的事实。
- 若在沙盒内启动辅助程序受阻，先报告具体原因和最小调整方案；不默认关闭 App Sandbox、Gatekeeper、SIP 或清除用户既有应用的隔离属性。
- W01 只生成测试级本机管理秘密。首次核心输出若包含初始化口令，只能由受控进程管道在内存中处理，不保存原始输出到日志；后续日志采用允许字段输出。不得把口令放进启动参数、URL、错误页面或截图。
- 如需跨启动保存测试会话材料，明确放在上述私有目录的受限文件中，纳入已确认的 A03 边界；不声称已经实现 W02 的系统秘密存储方案。

### 7.2 资源与缓存

Flutter 的 Git 检出、Dart/引擎和包缓存尽量放入 `.tools/`，应用构建产物放在项目构建目录。Xcode、自有 App 的系统容器以及工具不可避免的用户级缓存可能写入项目外，必须在执行记录列出实际位置；不承诺所有开发工具零外部写入。

暂以 **Flutter/项目依赖及构建区共预留 15GiB** 作为 W01-M 的准备预算，**不包含完整 Xcode**，不是已测得占用或产品缓存默认值。Xcode 的下载、解压和安装峰值在用户选定官方版本后单列；预算不足或出现未列的大组件，暂停扩大下载并说明。测试图及其运行工作区上限 64MiB，不使用真实大文件。

### 7.3 W01-A 已知差异，不能照搬现有 SDK

固定核心 go.mod 声明 `go 1.26.0`、`toolchain go1.27.3`；移动参考项目的 Gradle 声明 compileSdk 35、NDK 27.0.12077973、Java 17，gomobile 脚本另有 `androidapi 19`。本机现有 SDK/NDK 与参考组合不同。

这些是各文件的声明，不是本项目已验证的兼容组合；不能任取其中一个数值作应用整体最低版本。W01-A 在获准前还需固定 Go 工具链可取得版本、gomobile 提交、Gradle/插件和最终 ABI/SDK 组合，并列明是否新增组件。优先为用户现有 arm64 Android 设备构建单 ABI 开发包，不先生成所有架构，也不自动接受 SDK 许可或安装手机应用。

## 10. 失败、回退与清理

缺 Xcode/许可或 SDK 不兼容时停在对应环境问题，不改成 Web 页面冒充完成 Mac 宿主。辅助程序签名/沙盒继承、固定核心接口不符时，给出可复现的错误与最小方案，保留已经核实的版本基线。

清理只处理清单登记的 W01 测试输入、应用容器内测试运行数据、项目内工具/构建产物和身份已证实的自有进程。先停止核心，再处理其数据库/临时文件；不以扫描 `/private/tmp`、整个 Application Support 或按文件年龄删除的方式清理。旧百度验证工作区、用户原文件、现有 OpenList 及共享 Android SDK 都不在清理范围。

开发环境回退不自动卸载用户安装的 Xcode，不卸载共用工具、不修改系统安全设置。保留必要脱敏证据；含测试口令的原始日志不得借“留证”永久保存或进入 Git。

## 11. 决策与下一步

用户已批准 **W01-M 的环境准备、Mac 实现和本机验收**，执行范围为第 6—9 节。完整 Xcode 按最新决定由用户安装并确认许可；助手先完成可独立执行的准备和代码检查，再继续实际构建与验收。当前状态见报告 23，不以代码写入代替运行成功。

Mac 工具链版本、固定 Flutter 的本机兼容性、沙盒辅助程序与监督整合已取得运行证据。Android 的完整工具链组合等仍留在 W01-A；不重新打开已确认的 A01—A07 产品选择。

本提案经过用户明确批准后才进入实施。批准 W01-M 不包含 W01-A、真实云端/来源账户、VPS、Git 提交或发布；后续也不因为 Mac 通过就把这些范围默认加入。
